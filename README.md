# NetScan — 类 nmap 轻量网络扫描工具（带 Web 可视化界面）

NetScan 是一个用纯 Python 标准库实现的网络扫描工具，**无需安装任何第三方依赖**，
支持主机发现、TCP 端口扫描、服务识别（Banner 抓取），并提供实时进度的 Web 可视化界面。

> ⚠️ **免责声明**：本工具仅用于对您拥有授权的网络/主机进行安全测试与管理。
> 未经授权扫描他人网络在大多数国家和地区属于违法行为，请合法使用。

---

## 一、快速开始

```bash
# 1. 启动 Web 界面（自动打开浏览器）
python3 netscan.py web

# 2. 或使用命令行直接扫描
python3 netscan.py scan 127.0.0.1
```

要求：Python 3.10+（推荐 3.13），Linux / macOS / Windows 均可运行。
不需要 root 权限（使用 TCP connect 扫描，不是 SYN 扫描）。

## 二、Web 模式（可视化界面）

```bash
python3 netscan.py web                    # 默认监听 http://127.0.0.1:8000
python3 netscan.py web --port 9000        # 指定端口
python3 netscan.py web --host 0.0.0.0     # 允许局域网访问（注意安全）
python3 netscan.py web --no-browser       # 不自动打开浏览器
```

### 界面使用说明

1. **扫描目标**：填入 IP、CIDR、范围或域名，可混合，用逗号或空格分隔
   - 单个主机：`192.168.1.10`
   - CIDR 网段：`192.168.1.0/24`
   - IP 范围：`192.168.1.1-50`
   - 域名：`example.com`
2. **端口**：如 `22,80,443,1000-2000`；快捷选项 `top100`（内置常用 100 端口）、`1-1024`、`1-65535`
3. **超时 / 并发**：默认超时 1.5 秒、并发 500；内网可调小超时提速，公网建议 2-3 秒
4. **选项**：
   - `主机发现 + 抓 Banner`（默认）——先探测主机存活，只扫存活主机，并尝试读取服务 Banner
   - `跳过主机发现` ——直接对所有目标做端口扫描（目标可能禁 ping 式探测时使用）
   - `仅端口连通性`——最快，不抓 Banner
5. 点击 **开始扫描**，下方进度条实时显示进度；完成后结果表格列出每台主机的状态和开放端口
6. 点击某个 **端口标签**（如 `80/http`）可查看该服务的 Banner 详情
7. 点击 **导出 JSON** 可将本次结果下载保存

## 三、命令行模式

```bash
# 扫描单个主机的常用端口
python3 netscan.py scan 127.0.0.1

# 扫描网段的指定端口
python3 netscan.py scan 192.168.1.0/24 -p 22,80,443,3306,3389

# 扫描端口范围，自定义超时和并发
python3 netscan.py scan 10.0.0.1-100 -p 1-65535 -t 0.8 -c 800

# 跳过主机发现，结果保存为 JSON
python3 netscan.py scan example.com -p top100 --no-discovery -o result.json
```

### 命令行参数

| 参数 | 说明 | 默认值 |
|------|------|--------|
| `targets` | 目标：IP / CIDR / 范围 / 域名，逗号分隔 | 必填 |
| `-p, --ports` | 端口列表/范围，或 `top100` | `top100` |
| `-t, --timeout` | 单连接超时（秒） | `1.5` |
| `-c, --concurrency` | 最大并发连接数 | `500` |
| `--no-discovery` | 跳过主机发现，直接扫端口 | 关闭 |
| `-o, --output` | 结果保存为 JSON 文件 | 不保存 |

## 四、工作原理

- **主机发现**：对每个目标尝试连接 80/443/22/445/3389/8080 等常见端口，
  任一端口可连即判定存活（无需 root，可穿透禁 ICMP 的防火墙策略）。
- **端口扫描**：基于 asyncio 的 TCP connect 全连接扫描，单并发信号量控制速率；
  能连上即为开放（open），被拒/超时即关闭。
- **服务识别**：根据 IANA 常见端口 + `/etc/services` 给出服务名，
  并对开放端口发送轻量探测（HTTP GET、Redis PING 等）读取 Banner。
- **Web 服务**：标准库 `http.server` 提供页面与 JSON API（`POST /api/scan`、`GET /api/status/<id>`），
  扫描在后台线程执行，前端每 0.5 秒轮询进度。

### 与 nmap 的差距（如实说明）

本工具是轻量教学/自用工具：只支持 TCP connect 扫描（会留连接日志），
不支持 SYN 隐蔽扫描、UDP 扫描、OS 指纹识别、NSE 脚本等 nmap 高级功能。
需要深度探测时请使用真实 nmap。

## 五、常见问题

**Q：扫描很慢？**
调大并发 `-c 1000`、调小超时 `-t 0.5`，或先只扫 `top100` 而不是全端口。
扫描 65535 端口 × 254 主机属于重度任务，建议拆分网段。

**Q：显示"无响应"但主机明明在线？**
主机发现依赖 TCP 端口探测。若目标所有默认探测端口都被防火墙过滤，
尝试加 `--no-discovery`（Web 界面选"跳过主机发现"）直接扫端口。

**Q：防火墙/杀软报警？**
全连接扫描在目标日志中会留下记录，这是正常行为，也提醒您只在授权范围内使用。

**Q：Windows 上能用吗？**
能。所有代码仅用标准库，跨平台。`/etc/services` 不可用时自动回退到内置端口表。
